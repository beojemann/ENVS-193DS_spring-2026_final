# ENVS-193DS_spring-2026_final

## General information
This repository contains the final assignment for ENVS 193DS, Spring 2026, from Emilio Ojemann.
I complete three problems: a critique on research-writing critique of waterbird habitat-use, use a binomial GLM to look at how tree height and acacia ant species influence bird nest occurrence, and run a two-sample t-test
on a personal research project about dinner-cooking time.
